Jak zaimportować szablon onboardingowy?

  1. Pobierz przykładowy szablon CSV używając przycisku poniżej
  2. Otwórz plik w edytorze (Excel, Google Sheets, Notatnik)
  3. Format pliku CSV:
    • Pierwsza linia zawiera nagłówki kolumn
    • Każda kolejna linia to jedno zadanie dla stanowiska
  4. Wymagane kolumny (w tej kolejności):
    • position_name - nazwa stanowiska (np. "IT DevOps")
    • task_order - kolejność zadania (liczba: 1, 2, 3...)
    • task_title - tytuł zadania
    • task_description - opis zadania (opcjonalnie)
    • owner_role - kto wykonuje zadanie: USER lub MANAGER
  5. Właściciel zadania (owner_role):
    • USER - zadanie wykonywane przez nowego pracownika
    • MANAGER - zadanie wykonywane przez menedżera
  6. Zapisz plik i prześlij go za pomocą przycisku powyżej
